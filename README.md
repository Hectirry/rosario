# Rosario

App web personal para rezar el rosario desde el iPhone, en una sola pantalla.

- Toca la pantalla para avanzar cuenta por cuenta.
- Muestra los misterios del día (se pueden cambiar tocando el título).
- Incluye el texto de cada oración.
- Guarda por dónde ibas durante el día y funciona sin internet.

## Instalar en el iPhone

1. Abre https://hectirry.github.io/rosario/ en Safari.
2. Toca Compartir y luego "Agregar a pantalla de inicio".
